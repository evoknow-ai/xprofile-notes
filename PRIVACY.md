# Privacy Policy for X Profile Notes

Effective date: August 18, 2026

X Profile Notes is a local-first Chrome extension that lets users attach private notes and tags to X profiles.

## Data stored

The extension stores only the information entered by the user, including X handles, notes, tags, and local timestamps. This information is saved using `chrome.storage.local` inside the user's Chrome profile.

## Data collection and transmission

X Profile Notes does not collect, transmit, sell, share, or use personal data for advertising, analytics, credit decisions, or any purpose unrelated to its single purpose. It has no server, account system, telemetry, analytics, advertising, or remote code.

## Website access

The extension runs only on `x.com` and `twitter.com` so it can identify visible profile handles and add the private-note interface. Page information is processed locally and is not transmitted by the extension.

## Backup and deletion

Users may export their notes to a JSON file and import that file later. Users can delete individual notes inside the extension. Removing the extension may remove its locally stored data, so users should export a backup first if they wish to retain it.

## Changes

Material changes to this policy will be published in this repository with an updated effective date.
