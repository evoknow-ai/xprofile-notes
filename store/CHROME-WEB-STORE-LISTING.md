# Chrome Web Store Listing Copy

## Name

X Profile Notes

## Summary

Private, local-first notes and tags for people you encounter on X.

## Detailed description

Remember the person behind the handle.

X Profile Notes adds a private note button to X profiles and lets you keep personal context about people you meet through posts, replies, and Spaces.

Features:

- Add and edit private notes directly from X profile pages.
- Add notes from handles shown in timelines and profile lists.
- Preview an existing note by hovering over its blue pencil indicator.
- Organize people with tags.
- Search saved handles, notes, and tags from the extension popup.
- Open saved X profiles directly from the notes list.
- Export and import JSON backups.
- Keep all information in Chrome's local storage.

X Profile Notes is local-first. It has no account system, server, analytics, advertising, or tracking. Notes are not transmitted by the extension.

The extension is designed for the desktop X website at x.com and twitter.com. It is not affiliated with or endorsed by X Corp.
