# Privacy Practices Answers

## Single purpose

X Profile Notes lets a user privately attach locally stored notes and tags to profiles viewed on the X website and retrieve those notes while browsing X.

## Permission justification: storage

The `storage` permission is required to save the user's notes, tags, handles, and timestamps locally in the user's Chrome profile and to support local JSON backup and restore. The extension does not synchronize or transmit this data.

## Host permission justification: x.com and twitter.com

Access is limited to `https://x.com/*` and `https://twitter.com/*`. It is required to identify visible X profile handles and insert the note button, editor, and private note indicators into X pages. The extension does not request access to any other website.

## Remote code

Select: **No, I am not using remote code.**

All executable JavaScript and CSS are included in the extension package. The extension does not download or execute remote code.

## Data-use disclosure

Recommended selection: do not select any collected-data categories. The extension stores user-entered notes locally but does not collect or transmit them to the developer or a third party.

Certify all required limited-use statements truthfully. The extension does not sell or transfer user data, use data for unrelated purposes, use data for creditworthiness or lending, or permit human access to user data.
