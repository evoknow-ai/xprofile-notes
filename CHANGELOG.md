# Changelog

All notable changes to X Profile Notes are documented here.

## 1.2.0 · 2026-08-18

- Added a complete Chrome Web Store submission package.
- Added production icons for Chrome and the Web Store.
- Added promotional graphics, compliant screenshots, listing copy, privacy policy, permission justifications, and reviewer instructions.
- Updated the extension package for public store distribution.

## 1.1.2 · 2026-08-11

- Published the complete project to GitHub.
- Added GitHub and changelog links to the Credits page.
- Improved repository documentation.

## 1.1.1 · 2026-08-11

- Reduced the profile note button to a compact 34-pixel pill.
- Added explicit sizing overrides to prevent X from inflating the button.

## 1.1.0 · 2026-08-11

- Added a standalone Credits page.
- Added MIT License.
- Made handles in the notes list open their X profiles in a new tab.

## 1.0.2 · 2026-08-11

- Added a clear warning when Chrome invalidates an open X tab after an extension update.

## 1.0.1 · 2026-08-11

- Added a prominent note button directly to profile pages.
- Improved detection of dynamically rendered X handles.

## 1.0.0 · 2026-08-09

- Initial local-first release.
- Added inline note editing, hover previews, tags, search, export, and import.
